Build the R2C2 marketing site as the first site on R2C2.

- Write the R2C2 site theme (tokens and component classes) from the homepage design
- Rebuild the homepage as clean HTML in `sites/r2c2/` using only theme tokens and component classes, plus a contact section using `<site-form name="contact">`
- Import script that loads the theme and page into the seed site as a draft

Done when it passes the house rules, publishes through the Loft and renders correctly on the local edge.
