---
title: Add voice input to the Loft
created: 2026-10-28
---

Push-to-talk (hold Space on desktop, tap the mic on a phone), a live transcript, and a short plan before acting on multi-step requests. Spoken messages are marked with a mic. Start with an ADR choosing the speech-to-text service, because the browser's own speech recognition doesn't behave the same in every browser.

Done when a spoken request becomes a message in the conversation in desktop Chrome and Safari, and on iOS and Android.

Related: [Loft design spec §7](../../docs/design/loft.md#7-components), [§8](../../docs/design/loft.md#8-screens), [build-conversation-first-loft](build-conversation-first-loft.md)
